# 3D-printing-Extrusion-Cheat-sheet
A great beginning for extrusion based 3D printing.

Gels, inks, pastes, cementious, clays, ....

Finding it difficult to succesfully start 3D printing these materials? This cheat sheet is a starting point for your extrusion project. It tries to clarify and simplify the trial and error phase at the beginning of experimenting with a new material and guides you into finding good starting parameters for your first real print.
